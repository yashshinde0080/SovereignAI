# Zustand

A small, fast, and scalable state management library for [[React]] applications.

## Role in SovereignAI Edge

[[Zustand]] manages ==client-side state== in the SovereignAI Edge frontend:

- **Chat State:** Current conversation messages and streaming tokens
- **UI State:** Loading indicators, panel visibility, theme preferences
- **Model Selection:** Currently selected model and its status
- **Plugin State:** Enabled/disabled plugins in the current session

## Advantages

- **Tiny Bundle:** ~1KB, minimal impact on application size
- **Simple API:** No boilerplate or providers required
- **TypeScript:** Full type inference support
