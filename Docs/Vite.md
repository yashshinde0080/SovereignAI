# Vite

A fast build tool and development server for modern web projects.

## Role in SovereignAI Edge

[[Vite]] handles ==frontend bundling and development== for SovereignAI Edge:

- **Dev Server:** Hot Module Replacement (HMR) for rapid UI development
- **Production Build:** Optimized bundling with code splitting
- **Plugin Ecosystem:** [[Tailwind CSS]] integration via PostCSS plugin
