## Slide 2: The Problem

**Why SovereignAI Edge?**

- **Privacy crisis:** Cloud APIs leak sensitive data (enterprise IP, medical, legal, defense)
- **Connectivity gaps:** Air-gapped environments, remote work, travel, low-bandwidth regions
- **Cost at scale:** API fees compound — $0.002/1K tokens = $200/month per active user
- **Vendor lock-in:** Model deprecation, rate limits, terms-of-service changes
- **No true offline alternatives:** Existing tools require internet for model download, auth, or telemetry

**Our answer:** A platform that runs entirely on your hardware. Zero bytes leave your machine. Ever.

## Slide 5: Dual Engine Architecture

### FullRAM Engine — Maximum Throughput
- Loads **entire model** into RAM/VRAM via `transformers.AutoModelForCausalLM`
- Streaming via `TextIteratorStreamer` + `asyncio.to_thread()`
- GGUF fallback via `llama-cpp-python` / `ik-llama-cpp-python`
- **Best for:** 16GB+ RAM, dedicated GPU (8GB+ VRAM)
- **Performance:** 20-80+ tok/s on consumer GPUs

### LayerStream Engine — Memory-Bounded
- **Streams layers** from disk per forward pass (safetensors chunks)
- Preprocessing: `WeightSplitter` → per-layer `.safetensors` + `quant_config.json`
- Two-phase pipeline: Context prefill → Autoregressive decode
- KV cache in system RAM; VRAM footprint ~constant
- **Best for:** 8GB RAM, NVMe SSD, integrated graphics
- **Performance:** 0.4-8 tok/s (measured on 8GB device)

### CloudAPI Engine — Online Mode
- Proxies to OpenAI, Anthropic, Google, Mistral, Custom endpoints
- Encrypted API key storage (Fernet + PBKDF2HMAC)
- Streaming SSE from all provider types
- **Use when:** Local hardware insufficient or cloud preferred

## Slide 6: Engine Selection Logic

**Automatic at Model Load** (`ModelManager._load_model_locked()` → `EngineFactory.create_engine()`)

```
TaskResolver.resolve() → AutoConfig introspection
         │
         ▼
MemoryManager.suggest_mode() → llmfit.score_model_fit()
         │
         ├─ fit > 0.85 & RAM < 70%  → FullRAM
         ├─ fit > 0.60              → LayerStream
         └─ else                    → Insufficient (error)
         │
         ▼
Threshold Fallback (if llmfit unavailable):
  CUDA VRAM ≥ 1.1× model size → FullRAM
  RAM ≥ 1.1× model size       → FullRAM
  RAM ≥ 0.1× model size       → LayerStream
  Else                        → Insufficient
```

**Cloud mode (`mode=cloud`):** Bypasses all local checks — no model introspection needed.

## Slide 8: Data & Persistence (All Relative Paths)

```
./workspace/
├── models/           # GGUF checkpoints, HF cache, installed/
├── database/
│   ├── sovereign.db          # Models, sessions, docs, plugins, benchmarks
│   └── sovereign_settings.db # Settings (JSON blobs), agents, cloud providers
├── offload_cache/    # LayerStream per-layer safetensors
├── sessions/         # Chat snapshots
├── data/vector_index/ # FAISS index + metadata.db (RAG)
├── plugins/          # User Python scripts
└── logs/             # server_cli.log
```

- **Two SQLite DBs** (WAL mode, thread-local connections)
- **Encryption:** Fernet + PBKDF2HMAC (480k iterations) for model files & cloud API keys
- **Zero absolute paths** — USB-portable by design

## Slide 10: Security & Cloud Mode

### Local-First Security
- **Auth:** Bearer token (opt-in) — only enforced when `bind_localhost_only=false` AND `api_token` set
- **Encryption:** Machine-bound keys (platform.node() + uuid.getnode())
- **Rate limiting:** 60 req/min via slowapi
- **No telemetry:** Zero network calls unless CloudAPI engine explicitly used

### Cloud Mode (Optional)
- **Providers:** OpenAI, Anthropic, Google, Mistral, Custom (OpenAI-compatible: Together, Groq, vLLM, Ollama)
- **Keys:** Fernet-encrypted at rest in `sovereign_settings.db`, **never returned in GET** (masked only), never logged
- **Streaming:** SSE from all providers, unified chunk format
- **Switch:** `POST /v1/chat/mode/switch?mode=cloud`

## Slide 12: Roadmap & Status

### Current State (2026-09)
- ✅ FullRAM engine (transformers primary, llama.cpp fallback)
- ✅ LayerStream engine (validated on 8GB: Qwen2-0.5B 8 tok/s, Qwen3.5-0.8B hybrid 1.3 tok/s with device cache)
- ✅ CloudAPI engine (5 provider types, encrypted keys, streaming)
- ✅ Three UIs (Electron, Web, CLI) + Plugin system
- ✅ RAG (FAISS + sentence-transformers)
- ✅ Dual SQLite DBs, encryption, opt-in auth

### Known Gaps
- TurboQuant experimental, default OFF (eval gate fails)
- LayerStream hybrid models lack `causal-conv1d`/`fla` kernels (CPU fallback only)
- Plugin sandbox: timeout-only on Windows
- Test coverage gaps: RAG, e2e chat, hardware detector

### Next Milestones
1. LayerStream kernel support (causal-conv1d, fla) → 5-10× hybrid speedup
2. TurboQuant accuracy gate pass → enable by default
3. Plugin sandbox hardening (Windows isolation)
4. Cloud provider model registry sync
5. ARM64 Windows / Linux ARM Electron builds
