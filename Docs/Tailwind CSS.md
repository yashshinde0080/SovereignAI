# Tailwind CSS

A utility-first CSS framework for rapidly building custom user interfaces without leaving your HTML.

## Role in SovereignAI Edge

[[Tailwind CSS]] provides the ==styling foundation== for the SovereignAI Edge frontend:

- **Responsive Design:** Adapts chat UI across desktop and mobile
- **Dark Mode:** Built-in dark mode support for reduced eye strain
- **Custom Theme:** Matches SovereignAI Edge branding
- **Performance:** Generates minimal CSS through purging unused styles
