# SovereignAI Edge

**Portable Offline AI Platform**

Run AI models locally without internet connection. Dual execution engines for optimal performance on any hardware.

## Features

- 🚀 **Dual Execution Engines**: FullRAM for speed, LayerStream for low-memory systems
- 🔒 **Fully Offline**: No internet required after initial setup
- 📦 **Portable**: Run from USB or external SSD
- 🔌 **Plugin System**: Extend functionality with plugins
- 🌐 **Web UI**: Modern React-based interface
- ⌨️ **CLI**: Full-featured command line interface
- 🖥️ **Desktop App**: Native Electron application

## Quick Start

### Prerequisites

- Python 3.10+
- Node.js 18+ (for frontend/desktop)
- 8GB+ RAM recommended

### Installation

1. Clone or download the repository
2. Run the launcher:

**Linux/macOS:**
```bash
chmod +x launch.sh
./launch.sh
