# html_diagrams — shared build brief (diagram-design, sovereignai profile)

Every file in this folder is one self-contained HTML diagram built with the
`diagram-design` skill. This brief is the binding contract. Do not edit this file
from within a diagram task; follow it verbatim.

## Dials (fixed for the whole set)

- Format: `html` (self-contained single file, inline SVG, embedded CSS)
- Size: `doc-inline` — `viewBox="0 0 960 600"` exactly; extend height to `960 660` ONLY when the legend strip needs it (viewBox values stay divisible by 4)
- Detail: `balanced` — budget per diagram: ≤9 nodes, ≤12 arrows, ≤2 accent elements, ≤2 annotation callouts
- Audience: `mixed` — component names + plain verbs; mono sublabels only for real technical content (file names, endpoints, pragmas)
- Variant: minimal light only

## File / HTML contract

1. Start from `D:\SovereignAI\.agents\skills\diagram-design\assets\template.html`; reskin per above. Keep `.diagram-container { overflow-x:auto }`, `svg { min-width:960px }` (== viewBox width), and the `@media print` release placed AFTER the svg rule.
2. `<title>`, eyebrow text, and `<h1>` name the document (e.g. "Chat & API Flow").
3. SVG contract: `role="img"`, `aria-labelledby="<slug>-title <slug>-desc"`; `<title>` is FIRST child before `<defs>`; `<desc>` one content sentence; slug = filename stem (e.g. `02-chat-api-flow`).
4. `<defs>` defines all three markers: `arrow` (muted `#4a5578`), `arrow-accent` (`#3C3489`), `arrow-link` (`#12704f`). Background: plain `<rect fill="#f4f4f9"/>`, NO dot pattern.
5. Z-order: bg → zones → arrows → nodes → labels/masks → legend.
6. Legend = horizontal bottom strip with hairline separator (`rgba(25,26,43,0.10)` 0.8w) and `LEGEND` eyebrow; covers every type used and nothing extra; nothing else lives in the bottom 60px.
7. No shadows, no rounded-2xl (rx max 6–10 on boxes, rx=2 type tags), no vertical writing-mode text, coral/accent on ≤2 elements.

## Connector rules (SKILL.md §6 — automatic fail if broken)

1. Orthogonal only: straight `<line>` only when sharing x or y; otherwise rounded elbow paths `r=8` (`r=6` tight). Segments leave/enter box edges perpendicular, ports ≥8px from corners.
2. Every arrow label sits on an opaque `#f4f4f9` mask rect with a visible 6–10px gap from its stroke (label above horizontal lines, to the side of vertical ones — never on the line).
3. No overlapping/stacked connectors; parallel routes ≥12px apart; single crossings get a bridge/hop arc on the less-important (dashed/muted) arrow.
4. Multiple connectors on one edge fan to distinct attach points, ≥12px apart (8px min on small boxes).
5. No connector transits behind a non-endpoint box — reroute; if truly unavoidable, dashed `4,3`, label at visible end, no marker on the intervening box.
6. No label mask overlapping a node painted after it (masks fully inside a node as badges are fine).

Arrows drawn BEFORE boxes. Node box pattern: paper mask rect → styled box rx=6 → optional type tag rect rx=2 (7px eyebrow) → name (Oxanium 600 12) → sublabel (Source Code Pro 9, `muted`).
